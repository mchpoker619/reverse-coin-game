換成你要的音效：用「同樣的檔名」覆蓋就好，副檔名 .wav／.ogg／.mp3 都可以。
（同一個名字只放一個檔案；刪掉某個檔案＝那個聲音靜音）

  coin_hit   金幣互相碰撞（撞越大力越大聲）

  flip       弱點被打中、彈起翻面
  bgm        背景音樂（會一直循環播放）

遊戲中右上角「音效」「音樂」按鈕分開開關（N＝音效、M＝音樂）。
音量在 reverse_coin.py 開頭的 VOLUME 調整（sfx 音效、bgm 背景音樂，0～1）。
預設音效都是程式合成的原創聲音，可自由使用。
