逆轉金幣 3D 電腦版（Windows）
測試版推廣版本 請勿銷售利用

完全不需要網路，也不用裝 Python。

【直接玩】
  解壓縮整個資料夾 → 雙擊「執行遊戲.bat」
  會用 Edge（沒有的話用 Chrome）開成獨立視窗，沒有網址列，看起來就像一般程式。

【安裝到電腦（建議）】
  雙擊「安裝到電腦.bat」
  → 遊戲複製到 %LOCALAPPDATA%\ReverseCoin3D
  → 桌面和開始功能表出現「逆轉金幣 3D」捷徑（金幣圖示）
  之後解壓縮的資料夾可以刪掉。

【移除】
  雙擊「解除安裝.bat」（會刪掉捷徑和安裝資料夾）

【音效／背景音樂（可以自己換）】
  game\sounds 資料夾：coin_hit（金幣碰撞）、rail_hit（撞邊框）、flip（翻面）、bgm（背景音樂）
  用同樣檔名覆蓋就能換，.wav／.ogg／.mp3 都可以；刪掉＝那個聲音靜音。
  已安裝的話在 %LOCALAPPDATA%\ReverseCoin3D\game\sounds
  遊戲中右上「音效」「音樂」按鈕分開開關（N＝音效、M＝音樂）。

【檔案】
  game\ReverseCoin3D.html   遊戲本體（已內建 three.js、101 枚金幣圖、官方場地）
  game\icon.ico             捷徑圖示
  game\install.ps1／uninstall.ps1  安裝／移除程式

如果出現「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
